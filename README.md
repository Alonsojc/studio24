# Sistema para talleres de bordado

Sistema para talleres de bordado que necesitan controlar pedidos, clientes,
pagos, entregas, inventario y avances de produccion en un solo lugar.

Este producto forma parte de Janco:
https://janco.tech/sistemas/bordadoras

## Que resuelve

- Registro de clientes y pedidos.
- Seguimiento de etapas de produccion.
- Control de pagos y entregas.
- Inventario de materiales y productos.
- Reportes para operar con mas claridad.
